# 按需离线缓存与 CDN 请求优化

2026-10-09：用户要求减少作品集首次访问的 CDN 请求，授权覆盖原整站离线预下载方案。

旧构建预缓存 792 个文件、42,639,827 字节，其中 761 个字体相关文件。新构建仅预缓存 HTML、主 JS/CSS、manifest、favicon 与安装图标：10 个文件、1,730,267 字节（约 1.7 MiB）。其余 782 个资源不主动预下载，只有实际请求后才缓存。此数量是安装预缓存，不是总页面请求数。

首次 worker 接管时从资源性能记录取得本页面已请求的 URL，仅对清单内资源进行补缓存，优先使用浏览器 HTTP 缓存。按 URL 合并同时请求，重复访问直接读 Cache Storage。新版本标识仍覆盖完整资源内容；按需响应需匹配构建 SHA-256 才缓存，避免稳定文件名在部署后混入不同版本。激活新版本时仅复用哈希匹配的旧资源，不联网扫描全部资源；核心下载失败清理未完成的新缓存，保留旧版。收藏和偏好不变。

行为变化：已用资源可离线访问；未曾加载的查看器、音乐、TXT 或新增字符字体需要联网一次。基础缓存就绪不再宣称所有模型和音乐都可离线。更新后变更的按需资源也需要联网重新访问。原完整缓存可迁移，因此已有用户可能继续保有完整离线资源。

验证：TypeScript/Vite/PWA 构建通过；`scripts/check-pwa-demand.mjs` 在真实 Edge 中通过精简安装、旧缓存迁移、重复缓存命中、拒绝不匹配内容、已用资源离线、未用资源失败、明确应用更新、资源复用、更新下载失败及收藏保留。实际作品集全新桌面浏览器加载并离线重载通过，无页面错误；该本地检查记录 83 次初始请求、64 次字体请求（测试服务器统一 no-cache，包含首次补缓存请求），不是线上 Vercel 流量实测，也不代表所有视口、音乐偏好和页面的固定请求数。
